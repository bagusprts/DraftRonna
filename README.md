# DraftRonna

DraftRonna is a cloud-based, automated content management system featuring real-time data processing, auto-scaling, and load balancing gateway manager.

DraftRonna is built to be simple and practical, focusing on doing one thing well.

## Installation

1. Clone the repository: `git clone https://github.com/innayakendya/DraftRonna.git`
2. Install required dependencies: `pip install -r requirements.txt`

## Configuration

DraftRonna is configured through environment variables (see `.env.example`). Key options:
- **APP_ENV**: `development` or `production`.
- **PORT**: Port the server listens on.
- **LOG_LEVEL**: `debug`, `info`, or `error`.
